d · Method

Interventions are first given a role from the registry's arm structure (experimental, background, comparator, control-arm, placebo/sham, non-therapeutic, or unresolved). Only test-role drug-type interventions (experimental, experimental-inferred, unresolved-role) drive trial labels; background, comparator and control-arm treatments are kept in separate columns. Each test intervention is then labelled by: manual override → curated asset table (data/curation/asset_curation.csv: 37 rules, each with its source status) → name keywords (19 rules) → description keywords (modality only; mechanism as candidate) → registry-type fallback (modality only). The tier and rule behind every label are in data/interventions.csv.
